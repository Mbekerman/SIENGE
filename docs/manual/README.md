# Manual do usuário do ERP BKM

Este manual explica, passo a passo, o que você pode fazer no ERP BKM, como fazer e o que o sistema permite ou impede. Ele é escrito para quem nunca usou o sistema e serve também de roteiro para os vídeos de treinamento: cada tarefa tem um passo a passo numerado que pode ser gravado do jeito que está.

> **Atenção: o sistema ainda está em desenho (novembro de 2026).** Nenhuma tela existe ainda. Este manual descreve como o sistema **vai** funcionar, de acordo com as decisões já tomadas. Os nomes de botões e telas são provisórios e serão acertados quando as telas existirem.

## Como ler este manual

Cada regra traz uma marca que diz se ela já está decidida:

| Marca | O que quer dizer |
| --- | --- |
| ✅ **Decidido** | O Moises decidiu. Vale como regra do sistema. A data vem junto. |
| 🟡 **Proposta** | Foi sugerido no desenho e ainda falta o Moises confirmar. Pode mudar. |
| ⏳ **A definir** | O assunto ainda não foi discutido ou ficou para uma próxima sessão. |

Cada tarefa segue o mesmo formato, para virar vídeo sem adaptação:

1. **Para que serve**: o problema que a tarefa resolve.
2. **Quem faz**: o papel de quem executa.
3. **Antes de começar**: o que precisa existir antes.
4. **Passo a passo**: os passos numerados, na ordem da tela.
5. **O que o sistema confere**: as travas e avisos.
6. **E depois?**: para onde o trabalho segue.

## O ERP BKM em uma página

Hoje a BKM usa o Sienge para tudo. O ERP BKM é um conjunto de sistemas próprios em volta do Sienge, que passa a ser só o "motor" que processa o financeiro, o fiscal, o contábil e a conversa com os bancos. Você trabalha no ERP BKM; ele conversa com o Sienge por trás. Detalhes em [Visão geral](00-visao-geral.md).
