# Glossário

[← Sumário](README.md)

As palavras abaixo têm um sentido preciso no ERP BKM. Quando houver diferença em relação ao Sienge, ela está indicada.

| Palavra | O que quer dizer no ERP BKM |
| --- | --- |
| **Adiantamento** | Dinheiro pago a um fornecedor antes de existir a dívida. Fica como crédito com ele e é abatido aos poucos, em uma ou mais parcelas futuras. |
| **Alçada** | O limite de quem pode aprovar o quê (por valor, por idade do lançamento, por natureza, por empreendimento). |
| **Área** | Centro de custo que não é empreendimento, como a Sede. Substitui a "obra administrativa" do Sienge. |
| **Assinatura recorrente** | Compromisso que se repete (telefone, internet, aluguel, vigilância, ferramenta online), com periodicidade e valor estimado. Substitui o contrato fictício. |
| **Caução** | Parte do valor da nota que a BKM retém do fornecedor como garantia. Fica num extrato por contrato até ser liberada. |
| **Centro de custo** | Responde "de quem é o gasto": um empreendimento ou uma área. Nunca é a natureza do gasto. |
| **Compromisso** | O acordo que vai gerar gasto: contrato, pedido de compra, assinatura recorrente, despesa avulsa, guia de imposto ou folha. |
| **Competência** | O mês a que a despesa pertence (pode ser diferente do mês em que é paga). |
| **Data de caixa** | O dia em que o dinheiro sai ou entra no banco. |
| **Documento fiscal** | A nota, o boleto ou a guia que chegou e prova a dívida. |
| **Empreendimento** | O produto: o que se constrói e se vende. Cada empreendimento tem uma SPE. |
| **Empresa** | Qualquer pessoa jurídica do grupo: holding, incorporadora, SPEs. |
| **Estágio** | Em que ponto o valor está: orçado, previsto, comprometido ou realizado. |
| **Fechamento do mês** | O ato que trava os lançamentos de um mês. Depois dele, mudar algo exige alçada mais alta. |
| **Fluxo de caixa** | Não é cadastro: é uma visão que soma o previsto, o comprometido e o realizado por data de caixa. |
| **Liberação da medição** | Passo do Sienge que transforma a medição autorizada em título a pagar. Hoje só se faz à mão no Sienge. |
| **Livro de lançamentos** | A tabela única onde todo valor do sistema vira uma linha com as mesmas classificações. É de onde saem relatórios, BI e consultas. |
| **Medição** | O registro do quanto de um contrato foi executado num período; é o que gera a cobrança. |
| **Natureza** | Responde "que gasto é": Marketing, Folha, Fundações... Fica numa árvore única para toda a empresa. |
| **Pagamento** | O dinheiro que saiu do banco: uma operação, com conta, data e valor. |
| **Parcela** | Cada vencimento de um título. Um título pode ter muitas parcelas. |
| **Participação** | Quem é sócio de qual empresa, com o percentual e de quando até quando. |
| **Pessoa** | Qualquer um com quem a BKM se relaciona. Uma pessoa pode ser fornecedor, cliente, sócio, corretor e funcionário ao mesmo tempo. |
| **Previsão** | Gasto esperado que ainda não é dívida. Não vai para o Sienge. |
| **Quitação** | A ligação entre um pagamento e uma parcela: quanto daquele pagamento quitou aquela parcela, com juros, multa e desconto. |
| **Rateio** | Divisão de um gasto entre vários centros de custo ou naturezas, em percentuais. |
| **Reclassificação** | Mudar a natureza (ou outra classificação) de lançamentos já feitos. |
| **Retenção** | Imposto que a BKM desconta do fornecedor e paga direto ao governo (ISS, INSS, IR, PIS, COFINS, CSLL). |
| **SPE** | Sociedade de propósito específico: a empresa (CNPJ) criada para um empreendimento. |
| **Título** | A dívida real, que só nasce quando chega o documento. No Sienge, "título a pagar". |
